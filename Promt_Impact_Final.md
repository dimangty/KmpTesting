# СТРУКТУРА ОТВЕТА

Твой ответ должен содержать РОВНО 4 раздела в таком порядке:

## Раздел 1: Impact analysis

```markdown
# Impact analysis

- [Изменение 1] [КОД]: [описание]
- [Изменение 2] [КОД]: [описание]
  - [Подпункт если нужно]
- [Изменение 3] [КОД]: [описание]
```

### Цветовые коды:
- `#00F` = Low (текст, стили, мелкие правки)
- `#0F0` = Mid (логика, новые методы, изменения UI)
- `#F00` = High (новый экран, модуль, большое переписывание)

### Правила определения кода:
- Новый Screen/View → `#F00`
- Новая ViewModel → `#F00`
- Новая навигация/роут → `#0F0`
- Добавлена кнопка/карточка → `#0F0`
- Изменен текст/цвет → `#00F`

# АНАЛИЗ DIFF ФАЙЛА

При чтении diff обращай внимание:

### Новые файлы (`new file mode`)
```diff
+++ b/NewScreen.kt
```
→ Это новый функционал → `#F00` или `#0F0`

### Изменения в файлах
```diff
-старая строка
+новая строка
```
→ Анализируй ЧТО изменилось:
- Новый экран → `#F00`
- Новая кнопка → `#0F0`
- Изменен текст → `#00F`

### Паттерны в именах файлов:
- `*Screen.kt`, `*View.swift` → Экраны
- `*ViewModel.kt` → Логика
- `Navigation*.kt` → Навигация
- `strings.xml`, `*.storyboard` → Ресурсы
