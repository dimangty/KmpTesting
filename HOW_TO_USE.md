# Как использовать Impact Analysis Generator

## ✅ Готово к использованию

Все файлы созданы и сохранены:
- **Promt_Impact.md** - Основной промпт с инструкциями для LLM
- **create_impact_analysis.sh** - Автоматический скрипт
- **diff файлы** - Тестовые файлы для проверки

---

## 🚀 Рекомендуемый способ: OpenCode CLI

OpenCode CLI работает стабильнее и лучше форматирует вывод.

### Шаг 1: Создайте временный файл с промптом и diff

```bash
# Объедините промпт и diff
cat Promt_Impact.md review_master_app_only.diff > temp_analysis.txt
```

### Шаг 2: Запустите через OpenCode CLI

```bash
/Applications/OpenCode.app/Contents/MacOS/opencode-cli run \
  -m ollama/qwen2.5-coder:14b \
  < temp_analysis.txt \
  > review_master_app_only-impact.md
```

### Шаг 3: Просмотрите результат

```bash
cat review_master_app_only-impact.md
```

## 🛠️ Альтернативный способ: Скрипт

Использует встроенный скрипт:

```bash
./create_impact_analysis.sh review_master_app_only.diff
```

**⚠️ Известные проблемы:**
- Ollama выводит ANSI коды загрузки в файл
- Модели могут отвечать на английском вместо русского
- Большие модели (deepseek-coder:33b) могут вызывать ошибки ресурсов

## 🎯 Ожидаемый формат результата

```markdown
# Impact analysis

- Добавлен новый экран "Kitchen Tips" #F00: описание функционала
- Добавлена навигация #0F0: детали реализации
- Изменен экран профиля #0F0: что именно изменено

## Сверено с Figma

N/A

## Протестировано локально

- Тестовый кейс 1
- Тестовый кейс 2

## Рекомендации к тестированию

- Рекомендация 1
- Рекомендация 2
```

### Цветовые коды:
- **#00F** (Low) - тексты, стили, мелкие правки
- **#0F0** (Mid) - логика, UI компоненты, новые методы
- **#F00** (High) - новые экраны/модули, большие изменения

## 🐛 Решение проблем

### Проблема: Модель отвечает на английском

**Причина:** Модели Qwen плохо следуют инструкциям о русском языке при анализе английского кода.

**Решения:**
1. Попробуйте другую модель (если доступна русскоязычная)
2. Отредактируйте результат вручную - структура будет правильной
3. Используйте Claude через OpenCode Desktop для лучших результатов

### Проблема: Файл содержит ANSI коды

**Причина:** Ollama выводит spinner загрузки в stdout.

**Решение:**
```bash
# Очистите файл от ANSI кодов
sed 's/\x1b\[[0-9;]*[a-zA-Z?]//g' output-impact.md | grep -v "^\[" > cleaned-impact.md
```

### Проблема: Ошибка 500 - модель остановилась

**Причина:** Недостаточно памяти для большой модели.

**Решение:**
```bash
# Используйте меньшую модель
MODEL="qwen2.5-coder:7b"  # вместо 14b или 33b
```

## 📚 Примеры использования

### Пример 1: Один diff файл
```bash
./create_impact_analysis.sh review_master_app_only.diff
# Результат: review_master_app_only-impact.md
```

### Пример 2: Все diff файлы в папке
```bash
for diff in *.diff; do
    echo "Обрабатываю $diff..."
    ./create_impact_analysis.sh "$diff"
done
```

### Пример 3: С выбором модели
```bash
# Отредактируйте MODEL в скрипте или используйте напрямую:
cat Promt_Impact.md your-feature.diff | ollama run qwen2.5-coder:7b > output.md
```

## 💡 Советы

1. **Используйте OpenCode CLI** для более стабильной работы
